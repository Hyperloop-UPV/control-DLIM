# Decisions (ADRs)

Architectural decisions that shaped this template. New decisions get a
new file: `docs/decisions/YYYY-MM-DD-<short-topic>.md`.

A minimal ADR contains:

1. **Status** — Proposed / Accepted / Superseded.
2. **Context** — what is forcing a decision.
3. **Decision** — what we picked.
4. **Consequences** — what becomes easier and what becomes harder.
